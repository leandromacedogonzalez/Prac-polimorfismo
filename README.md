# Proyecto: Cálculo de sueldos de empleados
Este proyecto demuestra el uso de programación orientada a objetos en PHP para calcular el sueldo de distintos tipos de empleados.

## Funcionalidades
* Define una clase abstracta base llamada Empleado.
* Permite crear empleados fijos, por hora y vendedores.
* Cada tipo de empleado implementa su propio cálculo de sueldo.
* Ejemplo de uso incluido para mostrar los resultados en consola.

## Ejemplo
Se crean varios empleados y se calcula su sueldo:

* Empleado fijo: 50.000
* Empleado por hora: horas trabajadas × valor de la hora
* Vendedor: sueldo base + comisión por ventas

## Tecnologías
* PHP
## Como usarlo
Para utlizaralo, poner en la terminal(Teniendo instalado php):
* php.exe -S localhost:8000 index.php
